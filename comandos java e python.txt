##Para rodar os servidores:
Deves abrir um terminal para executar cada um dos comandos a baixo.

1. Servidor de nomes. Deves rodar o comando a baixo:

tnameserv -ORBInitialPort 1050 -J-Dcom.sun.CORBA.ORBServerHost=10.234.196.150

2.Servidor de pagamento. Deves estar na pasta backend/pagamento e rodar o comando:
java -cp "target/classes;target/dependency/*" com.grupo6.servidorPagamento   

3.Servidor de parqueamento. Deves estar na pasta backend/parque_estacionamento e rodar o comando:
java -cp "target/classes;target/dependency/*" com.grupo6.servidorParqueamento      



##Para rodar o frontend deves estar na pasta frontend e rodar o comando python main.py ou clicar no icone de play do vscode.
